Primer: obrazec na strani restavracije

Spodnjo kodo prilepite na stran restavracije (npr. podstran »Rezervacije«). Pot v src prilagodite svoji domeni. Višina okvirja se prilagodi sama.

<iframe id="rezervacije" src="/rezervacije/?embed=1" title="Rezervacija mize"
        style="width:100%;border:0;min-height:900px"></iframe>
<script>
  window.addEventListener("message", function (e) {
    if (e.data && e.data.type === "rezervacije:height")
      document.getElementById("rezervacije").style.height = e.data.height + "px";
  });
</script>
